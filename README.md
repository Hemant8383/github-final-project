# GitHub Final Project

## About
This project is part of the Introduction to Git and GitHub course.

The project contains a simple interest calculator written in Bash.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Use
Run the simple-interest.sh file and enter:
- Principal amount
- Rate of interest
- Time period

The program calculates and displays the simple interest.
